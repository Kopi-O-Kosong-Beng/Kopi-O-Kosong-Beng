<summary>为什么叫 kopi o kosong beng?</summary>
<br>

这就是我每次点的。Kopi 是咖啡,o 是不加奶,kosong 是不加糖,beng 是加冰。合起来:冰咖啡乌,不甜。

对,上面招牌里那杯是有冰的。故意的。
